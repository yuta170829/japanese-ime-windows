# kana-ime ― AIが後から直してくれる日本語入力 (Windows)

ローマ字で打った日本語を漢字に変換するアプリです。

- まず辞書で **すぐに** 変換を表示し、少し遅れて **AI (zenz) が直します**。AIが直した箇所はオレンジ色になります
- **タイプミスも自動で直します** (例: `tomxra` → `tomara`)。どこを直したかが画面に出て、Esc で取り消せます
- Space で候補を開くと、AIの別案も候補に並びます。クリックで選べます
- 入力した文章は外部に送りません。AIもこのパソコンの中だけで動きます。GPU は不要です

このアプリの画面の中で文章を書き、「コピー」ボタンでほかのアプリに貼り付けて使います
(Windows のすべてのアプリで使える正式な日本語入力 (IME) ではありません)。

## 必要なもの

- Windows 10 / 11 (64ビット)
- Python 3.10 以上 (64ビット) … [python.org](https://www.python.org/downloads/) から入れます。
  入れるときに **「Add python.exe to PATH」にチェック** を付けてください
- インターネット接続 (初回のセットアップのときだけ)
- 空き容量 約1GB

動作を確認したのは Python 3.10 です。

## はじめかた

1. このフォルダの **`setup.bat`** をダブルクリックします (初回だけ。10分ほどかかります)
2. 「完了しました」と出たら、**`kana-ime.bat`** をダブルクリックすると起動します
3. Windows の日本語入力 (Microsoft IME など) は **オフ (半角英数)** にしてから、ローマ字で打ちます

起動して数秒は「LLM 準備中」と出ます。その間も辞書の変換で入力できます。

## 使い方

| キー | 動作 |
|---|---|
| ローマ字 | 入力 (例: `kyouhagakkouniikimasu`)。「を」は `wo` |
| Space | 候補を開く / 次の候補 |
| ↑ ↓ | 候補を選ぶ |
| ← → | 文節を移動 |
| Enter | 確定 |
| Esc | AIの補正・タイプミスの補正を取り消す |
| 候補をクリック / ダブルクリック | その候補を選ぶ / 確定 |

右上のチェックで「AIによる補正」「タイプミスの自動補正」をそれぞれ切り替えられます。

## 注意

- 試作のアプリです。変換の精度は Microsoft IME などの製品より低く、AIの補正が外れることもあります
- 書いた文章は、このフォルダの `autosave.txt` に自動で保存されます (他人に渡すときは中身を消してください)
- 詳しい仕組みと評価の結果は `README.md` にあります

## 使っているもの (ライセンス)

| 名前 | 用途 | ライセンス |
|---|---|---|
| zenz-v3.2-small (Miwa-Keita) | 変換を直すAI。セットアップ時に Hugging Face から取得 | Apache-2.0 |
| llama-cpp-python | AIを動かす | MIT |
| pykakasi | 辞書の元データ (セットアップ時にこのPCで辞書を作ります) | GPL-3.0 |
| fugashi + ipadic (MeCab) | 動詞の活用の判定、読みの確認 | MIT / IPAdic ライセンス |
| jaconv | ひらがな・カタカナの変換 | MIT |
| gguf | モデルファイルの読み書き | MIT |

辞書ファイル (`*.pkl`) と AIのモデルは、このフォルダには入っていません。
`setup.bat` が、それぞれの配布元から取得して、このパソコンの中で作ります。
