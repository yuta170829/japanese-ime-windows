# azooKey-Windows 導入ガイド

[azooKey-Windows](https://github.com/fkunn1326/azooKey-Windows) は、AI (Zenzai) で文脈を読んで変換する日本語入力です。
Microsoft IME と同じように、Windows のすべてのアプリで使えます。

このガイドは、実際に Windows 11 に入れて使えるようにしたときの手順と、つまずいた点をまとめたものです。
azooKey-Windows 本体は fkunn1326 さんが作っているソフトで、このガイドの作成者のものではありません。

## 先に知っておいてほしいこと

入れる前に、次の4点を読んで、自分のパソコンに入れてよいか判断してください。

1. **試作版です。** 配布されているのは 2025年3月の `v0.1.0-alpha1` だけで、作者も「不具合が残っている」と書いています
2. **スマート アプリ コントロールをオフにする必要があります** (Windows 11 でオンになっている場合)。
   azooKey のプログラムには電子署名がないため、この安全機能に止められて動きません。
   オフにすると、知らない・署名のないプログラムを事前に止める守りがなくなります (ウイルス対策の Defender は動き続けます)。
   **以前の Windows では、一度オフにすると Windows を初期化しない限りオンに戻せませんでした。** 設定画面の説明を必ず読んでください
3. **ログインのたびに、管理者の権限で動きます。** azooKey の候補窓は、管理者として動かないと起動しない作りです。
   補助スクリプトは、これをログイン時に自動で行うタスクを登録します
4. **打つたびに少し待たされることがあります。** AI の計算が終わるまで画面が待つ作りのためです (速さはパソコンによります)

## 用意するもの

- Windows 10 / 11 (64ビット)
- 日本語が言語の一覧に入っていること (Microsoft IME が使えていれば大丈夫)
- 空き容量 約500MB
- このフォルダ (`セットアップ補助.bat`、`やめるとき.bat`、`setup_helper.ps1`)

## 手順

### 1. 復元ポイントを作る (おすすめ)

もしものときに、入れる前の状態に戻せるようにします。

1. スタートメニューで「**復元ポイントの作成**」と検索して開きます
2. 「システムの保護」タブの「**作成...**」を押し、名前に「azooKey導入前」と入れて「作成」を押します
3. 「作成」が押せないときは、「構成...」で「システムの保護を有効にする」を選んでから、もう一度押します

### 2. azooKey をインストールする

1. 公式の配布ページを開きます: [azooKey-Windows のリリース](https://github.com/fkunn1326/azooKey-Windows/releases)
2. `v0.1.0-alpha.1` の **`azookey-setup.exe`** (約206MB) をダウンロードします
3. (確かめたい人向け) ファイルの SHA-256 が次と一致すれば、このガイドを作ったときと同じファイルです。
   PowerShell で `Get-FileHash azookey-setup.exe` と打つと確かめられます
   `D5F836D4FF42928B5FF859ACF6F4CC988982309E3A3297F308958358034DBD7E`
4. ダブルクリックで実行します。「Windows によって PC が保護されました」と出たら、「**詳細情報**」→「**実行**」を押します
   (電子署名がないために出る警告です)
5. 許可画面で「はい」を押し、案内どおりに進めます

### 3. スマート アプリ コントロールを確認する

1. スタートメニューで「**Windows セキュリティ**」を開きます
2. 「アプリとブラウザーの制御」→「スマート アプリ コントロールの設定」を開きます
3. **オン** になっていたら、上の「先に知っておいてほしいこと」の2を読んだうえで、オフにするかを決めます。
   オフにしない場合、azooKey は使えません (手順はここで終わりです。`やめるとき.bat` と アンインストールで元に戻せます)

### 4. セットアップ補助を実行する

インストーラーだけでは、次の3つが行われませんでした。`セットアップ補助.bat` をダブルクリックすると、まとめて行います。

| 補助スクリプトが行うこと | 理由 |
|---|---|
| 日本語のキーボード一覧に azooKey を追加 | インストールしても一覧に入らなかった |
| Zenzai (AI の変換) をオン | 初期設定ではオフだった |
| ログイン時に、管理者として自動で起動するタスク「Azookey Engine」を登録 | 自動で起動せず、普通の権限では候補窓が起動しなかった |

途中で許可画面が1回出るので「はい」を押します。最後に「完了しました」と出れば成功です。

### 5. 使ってみる

1. メモ帳を開き、**Windowsキー + Space** で「**Azookey**」を選びます
2. 英字のまま出るときは、**半角/全角** キーで「あ」に切り替えます
3. ローマ字で打って、Space で変換、Enter で確定します

Microsoft IME に戻すときも、Windowsキー + Space です。

## 速さを変えたいとき

設定は `%APPDATA%\Azookey\settings.json` にあります (エクスプローラーのアドレス欄に `%APPDATA%\Azookey` と入れると開けます)。

```json
{
  "version": "0.1.0",
  "zenzai": { "enable": true, "profile": "", "backend": "cpu" }
}
```

- `"enable": false` にすると、AI を使わない辞書だけの変換になり、軽くなります (変換の精度は下がります)
- `"backend"` は `cpu` / `vulkan` (GPU) / `cuda` (NVIDIA の GPU と CUDA 12 が必要) から選べます。
  どれが速いかはパソコンによります。このガイドを作ったパソコン (Intel Iris Xe) では、
  CPU の方が Vulkan より約2.7倍速く出ました
- 変えたあとは、パソコンを再起動すると反映されます

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 一覧に Azookey が出てこない | `セットアップ補助.bat` を実行したか確認。それでも出ないときはサインアウトして入り直す |
| 選べるが、変換されない (英字のまま) | 半角/全角 キーで「あ」に切り替える |
| 選べるが、何も変換されない | 変換エンジンが動いていない。`セットアップ補助.bat` をもう一度実行する |
| 補助が「スマート アプリ コントロールがオン」と止まる | 手順3を参照 |
| パソコン全体の調子がおかしい | 手順1の復元ポイントに戻す |

調べたときの記録 (参考): 変換エンジンが動かない原因は、スマート アプリ コントロールによる停止 (エラー 4551) と、
候補窓 (`ui.exe`) が普通の権限では「アクセスが拒否されました」で終了することの2つでした。
候補窓は起動時に、Windows のログイン管理 (winlogon) の権限を借りて特別な表示権限 (UIAccess) を取るため、管理者として動く必要があります。

## やめるとき

1. `やめるとき.bat` をダブルクリックします (キーボード一覧から外し、自動起動のタスクを削除し、エンジンを止めます。許可画面が1回出ます)
2. 「設定」→「アプリ」→「インストールされているアプリ」から、「**Azookey バージョン 0.1.0-alpha.1**」と「**Azookey**」の2つをアンインストールします
3. スマート アプリ コントロールをオンに戻せるかは、Windows セキュリティの画面で確認してください
